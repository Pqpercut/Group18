In order to run the code, please follow the following steps:

1. Create a virtual environment, i.e. python -m venv venv
 
2. Enter the VE: venv\Scripts\activate
2.a. Or for mac users: source venv/bin/activate 

3. Install dependencies via: pip install -r requirements.txt
   
4. Run the server: python manage.py runserver
   
5. Navigate to local url provided in terminal
